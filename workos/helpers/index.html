Module helpers 

Source
Expand description

Hand-maintained helper layer.

These modules implement non-spec endpoints (Passwordless, Vault) and client-side helpers (webhook signature verification, PKCE, sealed sessions, JWKS, AuthKit/SSO URL builders, etc.) that oagen does not generate.
