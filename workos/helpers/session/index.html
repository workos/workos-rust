Module session 

Source
Expand description

Sealed sessions (H04, H05, H06, H07).

  • Seal/unseal: AES-256-GCM with a 32-byte key derived from a 64-char hex password. Nonce is prepended to ciphertext, then base64-encoded.
  • Authenticate: structurally validates a sealed session and parses JWT claims from the access token (signature is not verified — the cookie was sealed by us and trusted after unsealing).
  • Refresh: trades the refresh token at /user_management/authenticate and re-seals the new session.
