Expand description

Drive a paginated endpoint to exhaustion as an async stream of items.

fetch is called with the current after cursor (None on the first call). Each yielded Page contributes its data to the resulting stream; iteration stops when list_metadata.after is None. Errors short-circuit the stream.

ⓘ
use futures::TryStreamExt;

let stream = pagination::auto_paginate(|after| async {
    client.things().list(ListParams { after, ..Default::default() }).await
});
let all: Vec<Thing> = stream.try_collect().await?;
